# Data Science Bootcamp — Batch 09

This repository documents the work completed during a structured Data Science Bootcamp program. The program is divided into 13 sprints, each focused on a distinct skill area — from foundational spreadsheet tools through to machine learning and real-world project work.

---

## Program Overview

The bootcamp is organized into two parts. The first part builds core data literacy and tooling skills. The second part moves into applied analytics, statistics, and machine learning, culminating in a portfolio and a hackathon project.

---

## Sprint Index

### Part 1 — Core Data Skills

| Sprint | Topic | Description |
|---|---|---|
| SPRINT00 | Certificate | Program enrollment and credential documentation |
| SPRINT01 | Google Sheets | Spreadsheet fundamentals — formulas, pivot tables, and data organization |
| SPRINT02 | SQL Databases | Structured query language — SELECT, JOIN, GROUP BY, subqueries, and data extraction from relational databases |
| SPRINT03 | R Programming | Introduction to R — data types, vectors, data frames, and basic statistical operations |
| SPRINT04 | Data Transformation | Cleaning and reshaping raw data — handling missing values, type conversion, normalization, and feature engineering |
| SPRINT05 | Data Visualization | Constructing charts and visual summaries to communicate data findings — bar, line, scatter, and distribution plots |
| SPRINT06 | Essential Statistics | Descriptive and inferential statistics — measures of central tendency, distributions, hypothesis testing, and correlation |

### Part 2 — Applied Analytics and Machine Learning

| Sprint | Topic | Description |
|---|---|---|
| SPRINT07 | Portfolio | Building a personal web portfolio to document and present data science projects publicly |
| SPRINT08 | Dashboard | End-to-end dashboard development with Looker Studio, connecting live data sources to interactive visual reports |
| SPRINT09 | Machine Learning | Supervised learning models for data analysts — regression, classification, model evaluation, and feature importance |
| SPRINT10 | Python | Python for data analysis — pandas, numpy, matplotlib, and scripting for analytical workflows |
| SPRINT11 | MySQL | Relational database management using MySQL — schema design, indexing, stored procedures, and analytical queries |
| SPRINT12 | Hackathon | Capstone competitive project applying the full bootcamp skill set to a real-world problem under time constraints |
